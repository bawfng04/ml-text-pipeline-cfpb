\subsection{Thông tin tái lập thực nghiệm}
\textbf{Bước 1:} Cài thư viện.
\begin{verbatim}
pip install -r requirements.txt
\end{verbatim}

\textbf{Bước 2:} Chạy notebook pipeline (Colab hoặc local Jupyter).
\begin{verbatim}
jupyter notebook notebooks/main_pipeline.ipynb
\end{verbatim}

\textbf{Bước 3:} (Tùy chọn) chạy script thực thi notebook tự động.
\begin{verbatim}
python scripts/run_pipeline.py --notebook notebooks/main_pipeline.ipynb
\end{verbatim}

Khuyến nghị sửa môi trường:
\begin{itemize}[nosep]
    \item Cài lại \texttt{pytest} theo interpreter đang dùng.
    \item Hoặc chạy \texttt{python -m pytest -q} thay cho launcher trực tiếp.
\end{itemize}
